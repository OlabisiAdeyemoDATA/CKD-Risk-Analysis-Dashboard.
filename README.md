
Chronic Kidney Disease (CKD) Risk Analysis Dashboard
Project Overview
This Power BI project provides a comprehensive analytical tool for identifying and monitoring Chronic Kidney Disease risks within a patient population. The dashboard is designed to be "clinician-centric," translating complex medical metrics like eGFR, Albumin, and Blood Pressure into actionable insights and patient-friendly symptom explanations.

Key Features
Interactive Kidney Stage Navigator: A custom-built UX element where users can toggle through CKD Stages (1-5). The central kidney visual and "Note & Symptoms" section update dynamically to reflect the severity of each stage.

Static Risk Benchmarking: A specialized "High Risk Count" card that remains static across filters to provide a constant baseline of the most critical patients (Stages 4 & 5).

Clinical Diagnostic Gap Analysis: A visualization highlighting the percentage of CKD-positive patients who present with "normal" sugar and albumin levels, advocating for a multi-marker screening approach.

Data Quality Audit: A transparent look at missing clinical data, specifically identifying a 95.7% missing rate for RBC records in healthy patients, underscoring the need for improved data collection.
